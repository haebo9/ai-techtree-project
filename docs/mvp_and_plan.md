# 마지막 승부 (TechTree) 개발 계획 및 기능 정의

## 프로젝트 설명 
> 서비스의 방향성
- 서비스 이름 : 마지막 승부 (TechTree)
- 대상 : 취업 준비생 및 이직 준비자
- 목표 : AI를 통한 가상의 면접 경험 제공

## 완료된 기능 (Ver 2.1)
> 현재 구현이 완료된 서비스 핵심 기능
- 지원 희망 직무 및 개인 정보 입력 
    - 분야, 경력, 전공, 이력서 요약 텍스트 입력
- 이력서 파일 기반 면접 연동
    - 사용자의 이력서(PDF, TXT) 파일 업로드 기능 추가 및 텍스트 자동 추출
- 채용 공고 기반 맞춤형 면접
    - 채용 공고 텍스트 붙여넣기 및 캡처 이미지(Vision) 업로드 지원
    - 해당 공고의 자격 요건을 분석하여 AI가 맞춤형 질문 생성
- AI 면접관과의 실시간 양방향 대화
    - WebRTC 및 OpenAI Realtime API(gpt-realtime-mini) 기반의 음성 대화
    - 답변 문맥을 파악한 후속 꼬리 질문 제공
- 면접 종합 평가 리포트 생성 및 전송
    - LangGraph 기반 대화 분석 및 강점/개선점/Q&A 피드백 도출
    - 면접 중 실시간 채용 공고 검색 및 리포트 연동 (Tavily API)
    - 종합 리포트 이메일 발송 (Resend API 연동)
