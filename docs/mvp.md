# 최소 기능 개발 (MVP) for Ver2

## 프로젝트 설명 
> 서비스의 방향성
- 서비스 이름 : TechTree
- 대상 : 취업 준비생
- 목표 : AI를 통한 가상의 면접 경험을 제공

## 최소 기능 정의
> 서비스 제공을 위해 구현해야 할 최소한의 기능 
- 지원 희망 직무 및 개인 정보 입력 
    - 분야, 경력, 전공 등 정보
- AI 면접관과의 연속적인 대화
    - 연속적인 대화를 바탕으로 후속 질문 제공
    - 음성을 통한 대화 방식 사용
- 면접 종합 평가 리포트 생성 및 이메일 전송
    - 면접의 답변에 대한 피드백 제공 
    - 관련된 채용 정보 제공 
- 대화가 진행되는 최소한의 화면 구현
